# AI Mess Management System 🍽️

## About the Project

AI Mess Management System is a web-based application designed to simplify and improve daily mess operations. It provides a centralized platform for students, mess staff, and administrators to manage meal bookings, attendance, menus, payments, and complaints.

The system also integrates AI-powered features to support smarter decision-making, improve meal planning, reduce food wastage, and make complaint management more efficient.

## Key Features

### Student Module
- Secure login and registration.
- View daily and weekly meal menus.
- Book meals online.
- Check attendance records.
- View payment details.
- Submit and track complaints.

### Staff Module
- Manage daily meal activities.
- Monitor meal bookings and attendance.
- Access menu information.
- Manage food serving activities.

### Admin Module
- Manage student and staff accounts.
- Update and manage meal menus.
- Monitor overall mess operations.
- Manage payments and complaints.
- Access the administration dashboard.

## AI-Powered Features

### 1. AI-Based Meal Demand Prediction
Predicts expected meal demand using meal-related data to support better planning.

### 2. Smart Food Quantity Suggestions
Provides intelligent food quantity suggestions based on expected demand to help minimize food wastage.

### 3. AI-Based Complaint Analysis
Analyzes student complaints to identify issues and support better complaint management.
